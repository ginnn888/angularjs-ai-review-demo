# ทดลองตรวจคุณภาพโค้ดด้วย AI

## Prompt ตัวอย่าง

ตรวจโค้ด AngularJS ใน src/ และ index.html พร้อม package.json และ test/ วิเคราะห์ correctness, security, maintainability, accessibility และ test coverage รายงานเฉพาะประเด็นที่มีหลักฐาน พร้อมไฟล์ บรรทัด ระดับความรุนแรง วิธีทำให้เกิดปัญหา และแนวทางแก้ แยกข้อจำกัดจาก dependency ที่หมดอายุออกจากบั๊กของแอป ห้ามถือว่าการทดสอบผ่านหมายถึงไม่มีบั๊ก

## จุดตรวจ

- การตรวจ input และข้อมูลที่อ่านจาก localStorage
- พฤติกรรมเมื่อพื้นที่เก็บข้อมูลเต็มหรือถูกปิด
- การแสดงข้อความจากผู้ใช้และ XSS
- dependency injection เมื่อ minify
- keyboard navigation, label และข้อความแจ้งข้อผิดพลาด
- dependency เก่าและความครอบคลุมของ tests

## ทดลองเปรียบเทียบผลรีวิว

โค้ดเริ่มต้นไม่ได้ตั้งใจใส่ช่องโหว่ หากต้องการวัดความสามารถในการหาบั๊ก ให้ทำสำเนาหรือแยก branch แล้วทดลองทีละข้อ:

1. เอา trim ออกจาก validation แล้วเพิ่มงานเป็นช่องว่าง
2. เอา try/catch ออกจากการอ่าน localStorage แล้วใส่ JSON ที่เสีย
3. เอาการย้อนสถานะ checkbox เมื่อบันทึกล้มเหลวออก
4. เอา track by task.id ออกจาก template แล้วเปรียบเทียบผลรีวิวด้านประสิทธิภาพ

บันทึก diff, ผลที่คาดหวัง และผล AI review ในแต่ละรอบ ข้อ 4 เป็นโจทย์วิเคราะห์ ไม่จำเป็นต้องเป็นบั๊กเสมอไป
